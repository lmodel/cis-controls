# Control 12

Control 12 is one of the 18 Controls of the CIS Controls, Version 8.1. CIS's guide, at its v8.1.2 revision, lists 8 Safeguards under it, numbered 12.1 to 12.8.[^cis-v8-1] The schema uses those numbers as their identifiers. Of the Safeguards, 1 is in Implementation Group 1, 7 in Implementation Group 2 and all 8 in Implementation Group 3. Its Safeguards are about the asset classes Network (5), Devices (2) and Documentation (1).

This bundle leaves out CIS's name and description for the Control and CIS's text for its Safeguards, because CIS licenses that text under CC BY-NC-ND 4.0; CIS's guide gives them, and [the guide's reference](../references/cis-controls-guide.md) says where to find it. The edition file gives the Control and each of its Safeguards a title and a description in the project's own words, written from what each requires.[^edition] For Control 12 they are:

- **Title:** Managing network equipment
- **Description:** Setting up, tracking and correcting the enterprise's network devices so that attackers cannot exploit weak network services and access points.
