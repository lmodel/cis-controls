# Control 18 (CIS-18)

Control 18 is one of the 18 Controls of the CIS Controls, Version 8.1. CIS's guide, at its v8.1.2 revision, lists 5 Safeguards under it, numbered 18.1 to 18.5, which the schema names `CIS-18.1` to `CIS-18.5`.[^cis-v8-1] Of these, none is in Implementation Group 1, 3 in Implementation Group 2 and all 5 in Implementation Group 3. Its Safeguards are about the asset classes Network (4) and Documentation (1).

This bundle carries none of CIS's text, which CIS licenses under CC BY-NC-ND 4.0, so the Control's name, its description and the text of its Safeguards are left out. CIS's guide gives them; [the guide's reference](../references/cis-controls-guide.md) says where it is.
