# Control 11

Control 11 is one of the 18 Controls of the CIS Controls, Version 8.1. CIS's guide, at its v8.1.2 revision, lists 5 Safeguards under it, numbered 11.1 to 11.5.[^cis-v8-1] The schema uses those numbers as their identifiers. Of the Safeguards, 4 are in Implementation Group 1, all 5 in Implementation Group 2 and all 5 in Implementation Group 3. Its Safeguards are about the asset classes Data (4) and Documentation (1).

This bundle leaves out CIS's name and description for the Control and CIS's text for its Safeguards, because CIS licenses that text under CC BY-NC-ND 4.0; CIS's guide gives them, and [the guide's reference](../references/cis-controls-guide.md) says where to find it. The edition file gives the Control and each of its Safeguards a title and a description in the project's own words, written from what each requires.[^edition] For Control 11 they are:

- **Title:** Recovering data
- **Description:** Being able to restore the enterprise's systems and data to a known, trusted state from before an incident.
