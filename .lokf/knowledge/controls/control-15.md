# Control 15

Control 15 is one of the 18 Controls of the CIS Controls, Version 8.1. CIS's guide, at its v8.1.2 revision, lists 7 Safeguards under it, numbered 15.1 to 15.7.[^cis-v8-1] The schema uses those numbers as their identifiers. Of the Safeguards, 1 is in Implementation Group 1, 4 in Implementation Group 2 and all 7 in Implementation Group 3. Its Safeguards are about the asset classes Users (3), Data (2) and Documentation (2).

This bundle leaves out CIS's name and description for the Control and CIS's text for its Safeguards, because CIS licenses that text under CC BY-NC-ND 4.0; CIS's guide gives them, and [the guide's reference](../references/cis-controls-guide.md) says where to find it. The edition file describes the Control and each of its Safeguards in the project's own words, written from what each requires.[^edition]
