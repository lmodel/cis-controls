# Control 10

Control 10 is one of the 18 Controls of the CIS Controls, Version 8.1. CIS's guide, at its v8.1.2 revision, lists 7 Safeguards under it, numbered 10.1 to 10.7.[^cis-v8-1] The schema uses those numbers as their identifiers. Of the Safeguards, 3 are in Implementation Group 1, all 7 in Implementation Group 2 and all 7 in Implementation Group 3. All its Safeguards are about the asset class Devices.

This bundle leaves out CIS's name and description for the Control and CIS's text for its Safeguards, because CIS licenses that text under CC BY-NC-ND 4.0; CIS's guide gives them, and [the guide's reference](../references/cis-controls-guide.md) says where to find it. The edition file gives the Control and each of its Safeguards a title and a description in the project's own words, written from what each requires.[^edition] For Control 10 they are:

- **Title:** Defending against malware
- **Description:** Preventing or containing the installation, spread and running of malicious programs, code and scripts on the enterprise's devices.
